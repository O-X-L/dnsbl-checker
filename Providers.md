# DNS-BL Providers

If you use these DNS-BLs repeatedly - please make sure to **read the usage policies of those providers**.

Some like Spamhaus do not allow commercial usage of their free public mirrors!

Tip: If DNS-BL providers have no website or the website-design is from 2000 - maybe skip those.. (;

Other provider that could be added: [Long List](https://multirbl.valli.org/list/)
